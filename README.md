# Gossyp (chat app using socket.io)

A real-time full-stack chat application built with the MERN stack (MongoDB, Express, React, Node.js) and Socket.IO.  
This app supports instant messaging, online/offline status tracking, unread message counts, photo sharing, and user authentication.

**Live Demo:** https://gossyp-ebon.vercel.app/

---

## Features

- User authentication (register / login)
- Real-time messaging with Socket.IO
- Online / offline presence indicators
- Unread messages counter
- Image (photo) sharing within chats
- MongoDB-backed persistent storage for users and messages
- Deployed on Vercel
